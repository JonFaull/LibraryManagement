# 📚 Library Management API

A RESTful Web API built with ASP.NET Core for managing books, students, and checkouts in a library system.

## 🚀 Technologies Used

- ASP.NET Core 9.0
- Entity Framework Core
- SQL Server
- AutoMapper
- JWT Authentication
- Swagger (OpenAPI)

## 📦 Features

- ✅ CRUD operations for Books and Students
- 📖 Book checkout and return tracking
- 🔐 Role-based authentication (`Admin`, `User`)
- 📄 JSON Patch support for partial updates
- 📊 Swagger UI for interactive API documentation
